## Why Starlight here

This per-repo site is the **flagship seed** for one org docs hub on the custom domain (set in `.lakehouse/org.json` when Sen chooses it). It matches the monorepo Astro stack, ships sitemap/robots/OG/JSON-LD, and stays zero-cost on GitHub Pages or Vercel free — without using `*.github.io` as the public hostname.
