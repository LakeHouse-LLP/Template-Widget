---
title: Releasing and ranking
description: Why regular releases help discoverability for LakeHouse Studio public templates.
---

Regular **annotated `vX.Y.Z` tags** and draft-then-publish GitHub Releases help ranking and trust:

- GitHub search and dependency graphs surface maintained projects
- Release notes feed social/launch posts
- npm OIDC publishes keep the package scope (`@lakehouse`) visible

Follow the repository release pipeline (changesets → CI tag → attestations → draft release). Never tag by hand.
