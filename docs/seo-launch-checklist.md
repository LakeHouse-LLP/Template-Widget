Use with [pre-release-checklist.md](./pre-release-checklist.md) and [sen-seo-verification.md](./sen-seo-verification.md).

## Product readiness

- [ ] GitHub description + 8–20 topics applied (Sen) per `.lakehouse/discoverability.json`

- [ ] Social preview uploaded (1280×640)
- [ ] Docs site deployed or build-verified (`cd site && npm ci && npm run build`)
- [ ] Demo GIF/video in `docs/media/demos/` with alt text / captions

- [ ] LinkedIn + X (LakeHouse Studio voice; accent visuals from brand placeholders)
