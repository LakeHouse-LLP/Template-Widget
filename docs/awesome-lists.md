# Submitting to awesome lists

Zero-cost discovery channel.

## Preparation

- [ ] README keyword paragraph + badges green
- [ ] Description/topics set (Sen)
- [ ] At least one GitHub Release
- [ ] Docs site buildable (`site/`)
- [ ] CITATION.cff present
- [ ] Demo GIF/MP4 under `docs/media/demos/` (no client data)

## Targets (examples)

- Awesome lists for Revit / Dynamo / Rhino / Grasshopper / BIM / AEC open source
- `awesome-architecture` / computational design lists
- Language/stack lists only if the tool is genuinely that stack’s showcase

## PR etiquette

- One project per PR; match the list’s format exactly
- Link the **custom domain** docs when live; otherwise GitHub repo URL
- Never paste client names or proprietary screenshots
- Mention license status honestly (pending vs Apache-2.0)
